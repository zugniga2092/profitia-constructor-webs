# Constructor de webs Profitia

**La web de tu negocio (o la de alguien que conozcas), hecha conversando con Claude Code,
publicada gratis y con tu propio dominio. Sin saber programar.**

Hecho por [Profitia](https://profitia.digital) para la comunidad de la Academia.

## Qué consigues
- Una web de una página, pensada para tu negocio: no una plantilla que tiene todo el mundo.
- Textos que suenan a ti, no a una IA.
- **Segura desde el principio**: cabeceras de seguridad, sin secretos dentro, candado HTTPS.
- **Con lo legal de España resuelto**: aviso legal, privacidad y sin cookies que obliguen a un banner.
- **Publicada gratis** en Cloudflare, y con tu dominio conectado.
- **Sin instalar nada más**: ni Node, ni programas raros. Solo Claude Code.

## Lo que necesitas
- **Claude Code** (necesita un plan de pago de Claude: Pro o superior).
- **Una carpeta en tu ordenador** con este kit (abajo cómo).
- **Un dominio**, si quieres tu propia dirección (desde pocos euros el primer año). Opcional.
- Una hora tranquila.

## Cómo empezar

**1. Descarga el kit.** Elige una:
- Con Git: abre la terminal y escribe
  ```
  git clone https://github.com/zugniga2092/profitia-constructor-webs.git
  ```
- Sin Git: en esta página, botón verde **Code** → **Download ZIP**, y descomprímelo.

**2. Si tienes logo o fotos**, guárdalos en la carpeta `mis-cosas`.

**3. Abre Claude Code en la carpeta del kit.**
- En la terminal: `cd profitia-constructor-webs` y luego `claude`.
- En la app de Claude: pestaña **Code** → elige la carpeta.

**4. Escríbele:** «Hola, quiero hacer la web de mi negocio». A partir de ahí te guía él.

## Cómo trabaja
| | Qué pasa | Qué haces tú |
|---|---|---|
| 1 | Te entrevista sobre el negocio | Respondes (o dices «decide tú») |
| 2 | Te propone dos estilos | Eliges uno |
| 3 | Construye la web entera | Esperas unos minutos |
| 4 | Te la enseña | Pides cambios |
| 5 | Revisa calidad, seguridad y lo legal | Le das los datos que falten |
| 6 | Te guía para publicarla y poner tu dominio | Sigues los pasos en tus cuentas |

Toda la explicación de cada paso está en la carpeta `docs/`, por si quieres leerla.

## Lo que cuesta
| | |
|---|---|
| Este kit | Gratis |
| Alojamiento (Cloudflare Pages) | Gratis |
| Candado HTTPS y correo de reenvío | Gratis |
| Dominio | Lo que cobre tu registrador. **Mira el precio de renovación, no solo el del primer año** |

## Tres consejos de seguridad
1. Activa la verificación en dos pasos en tu correo, en la cuenta del dominio y en Cloudflare.
2. Nunca pegues contraseñas en el chat ni las pongas en la web.
3. Si te llega un correo de «tu dominio caduca, paga aquí», no pulses: entra tú en la web de tu registrador.
