# Ejemplo: La Espiga

Web hecha con este kit para un negocio **inventado** (una panadería de barrio en Valencia), como listón de calidad.
Todos los datos de contacto y legales son de ejemplo: mira `contenido-inventado.md`.

Para verla: abre `index.html` en el navegador. Fíjate en cómo sale todo de una sola idea del negocio
(la hora a la que sale el pan) y en que no hay ni una reseña ni una cifra inventada.
